# SkyTracker: Система Мониторинга Самолетов (Авиатрекер)

Курсовая работа по дисциплине **«Объектно-ориентированное программирование на Python»**.
Проект разработан в строгом соответствии с принципами **SOLID** и архитектурными стандартами разработки.

## 📌 Описание проекта
**SkyTracker** — это консольное приложение, предназначенное для отслеживания воздушных судов в режиме реального времени над территорией выбранной страны. 

Программа интегрируется с двумя внешними REST API:
1. **OpenStreetMap Nominatim API** — используется для геокодинга (получения географических границ `boundingbox` страны по её названию).
2. **OpenSky Network API** — используется для получения актуальных векторов состояния (координаты, скорость, высота полета, позывные) самолетов, находящихся внутри заданных границ.

## 🛠️ Используемые технологии и инструменты
* **Язык программирования:** Python >= 3.10
* **Инструменты контроля качества (Линтеры):** `flake8`, `mypy` (строгая статическая типизация)
* **Форматирование кода:** `black`, `isort`
* **Тестирование:** `pytest` (автоматизированное модульное тестирование)
* **Цветное логирование:** Встроенный модуль `logging` с ANSI-окрашиванием (`INFO` — белый, ошибки/предупреждения — красный).

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd SkyTracker
```

### 2. Активация виртуального окружения
```bash
# Для Windows:
.venv\Scripts\activate

```

### 3. Установка зависимостей
Пакеты установятся в соответствии с конфигурацией в `pyproject.toml`:
```bash
pip install -r requirements.txt
# или вручную:
pip install requests flake8 mypy black isort pytest
```

### 4. Запуск приложения
```bash
python main.py
```

## 💡 Принцип работы (Интерфейс)
1. При запуске программа предлагает ввести название страны на английском языке (например, `France`, `Spain`, `Canada`).
2. Приложение запрашивает координаты границ у OpenStreetMap, после чего сканирует небо через OpenSky API.
3. Все полученные борты автоматически конвертируются в объекты класса `Aeroplane` и сохраняются локально в JSON-базу, исключая дубликаты.
4. Пользователь настраивает фильтры: количество выводимых строк (ТОП-N), интересующие страны регистрации судов и желаемый диапазон высот полета.
5. Программа сортирует самолеты по **убыванию высоты полета** (при равенстве высот — по убыванию скорости) и выводит структурированный результат в консоль.
